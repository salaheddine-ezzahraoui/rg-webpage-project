# 🌐 Webpage Hosting on Microsoft Azure

## Project Overview
This project demonstrates hosting a simple **HTML/CSS webpage** on **Microsoft Azure** using **App Service**. It highlights manual deployment of web content to the cloud, making it ideal for showcasing personal projects.

## Technologies Used
- **Microsoft Azure** – Cloud platform  
- **Azure App Service** – Web hosting service  
- **HTML & CSS** – Frontend development  

## Deployment Steps
1. **Create a Resource Group** in Azure to organize all related resources.  
2. **Set up an App Service** within the Resource Group to host your webpage.  
3. **Upload your HTML/CSS files manually** through the Azure Portal.  
4. **View your webpage** using the Azure-provided URL (managed via App Service).
